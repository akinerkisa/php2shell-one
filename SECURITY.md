# Security policy

The Response Kit is a defensive utility and does not send PHP exploit traffic.

**High-impact bug class:** Any tool path that incorrectly labels an unverified runtime as `FIXED_RUNTIME`, executes an untrusted command, leaks credentials into reports or contacts a network target without explicit authorization.

Until a maintainer has provided a dedicated security contact on the GitHub repository, report issues privately to the maintainer of the fork you are using. Do not post an unpatched high-impact flaw with an active exploit to public issues. No private email address is invented by this repository.

Do not attach secrets, customer traffic, live exploit samples or sensitive logs to public tickets. Project maintainers can change this policy upon publication.
